## 4. System Design

## 5. Production Engineering
Evaluation, observability, security, guardrails, latency, caching, cost optimization, scalability, reliability, governance, and human-in-the-loop design.

## Recommended Paths

**Beginner:** AI/ML → Transformers → LLMs → Prompting → Embeddings → RAG

**Applied AI Engineer:** LLMs → Prompting → RAG → Tool Use → Agents → Evaluation → Production

**Agentic AI Engineer:** LLMs → Tool Use → Agents → Memory → Planning → Multi-Agent → MCP → A2A → Evaluation

**System Design / Interview:** LLM Architecture → RAG Design → Agent Design → Production Concerns → Case Studies → Trade-offs
