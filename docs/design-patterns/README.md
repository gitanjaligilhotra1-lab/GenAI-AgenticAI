# GenAI & Agentic AI Design Patterns

A catalog of reusable patterns for building reliable AI applications.

## RAG Patterns
Basic RAG, Hybrid Retrieval, Query Rewriting, Reranking, Parent-Child Retrieval, Corrective RAG, and Agentic RAG.

## Agent Patterns
ReAct, Plan-and-Execute, Router, Supervisor/Worker, Reflection, Human-in-the-Loop, Parallel Agents, and Hierarchical Agents.

## Memory Patterns
Conversation Buffer, Summarized Memory, Semantic Memory, Episodic Memory, and Long-Term Memory.

## Reliability Patterns
Retry and Backoff, Fallback Models, Validation and Structured Output, Guardrails, Circuit Breakers, and Tool Permission Boundaries.

Each pattern should explain when to use it, architecture, flow, implementation approach, trade-offs, failure modes, and production considerations.
